Tomafoco 1.17

Importante: esta versão exige macOS 14 Sonoma ou superior. Seus dados passam para um banco de dados na primeira abertura — a migração é automática e os arquivos antigos ficam guardados. Depois de atualizar, não volte para uma versão anterior.

Projetos

  • Cadastro de projetos com título, vencimento, descrição, cor e ícone (botão Projetos… na janela Tarefas e no Kanban).
  • Cada tarefa pode ficar num projeto; subtarefas acompanham o projeto da tarefa pai.
  • Selo colorido do projeto na lista e nos cartões do Kanban, e filtro por projeto — com um projeto filtrado, a tarefa criada já nasce nele.

Relatório de projetos

  • Novo menu Relatórios ▸ Tarefas / Projetos.
  • Escolha o projeto e o período para ver as tarefas com o tempo de foco de cada uma e o total de horas — e gere um PDF para salvar ou imprimir.

Datas

  • O filtro Hoje agora traz também as tarefas atrasadas de dias anteriores.
  • Subtarefa não aparece mais como atrasada só porque a tarefa pai está atrasada.
  • Lembretes de "dia inteiro" importados vencem às 23:59, não à meia-noite.
  • O destaque de atrasada se atualiza sozinho com a janela aberta.

Por dentro

  • Dados num banco de dados local (mais rápido para ler e gravar).
