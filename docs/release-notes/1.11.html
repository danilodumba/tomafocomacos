Tomafoco 1.11

Sites: bloqueio por caminho

  • Agora dá para bloquear só uma parte de um site: www.youtube.com/shorts bloqueia os Shorts, mas deixa o resto do YouTube liberado.
  • O caminho vale para ele e tudo abaixo dele (/shorts/abc), nunca para páginas parecidas (/shortsxyz).
  • Combina com o curinga: *.youtube.com/shorts pega também m.youtube.com.
