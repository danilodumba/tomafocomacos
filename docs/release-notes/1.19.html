Tomafoco 1.19

Documento em markdown nas tarefas

  • Cada tarefa ganha um documento próprio em markdown, editado numa janela separada com os modos Editar, Lado a lado e Visualizar. Salva sozinho.
  • Títulos, listas, tabelas, código, citações e links formatados na visualização.
  • Checklist clicável: marcar um item na visualização atualiza o texto.
  • Barra de formatação com atalhos ⌘B, ⌘I e ⌘K.
  • Copiar o markdown ou exportar como .md.
  • Abre pelo formulário da tarefa, pelo menu de contexto (lista e Kanban) ou pelo selo Doc.
  • Tarefa diária: a cópia de amanhã leva o documento com o checklist desmarcado.

O primeiro lançamento atualiza o banco de dados para o novo formato. Voltar para uma versão anterior depois disso não é suportado.
